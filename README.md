# Perfect Salon

React + Vite + TypeScript + Tailwind CSS

## Desks

### Executive Desk (homepage — no login)
- Cutter profiles
- Daily income + expense per cutter
- Shop expense daily

### Management Desk (secure login)
- Add / edit cutters
- Total income per cutter (daily)
- Total expense per cutter (daily)
- Shop expense summary
- Cosmetics / item stock
- Shop rent + total monthly expense

## Run

```bash
pnpm install
pnpm dev
```
